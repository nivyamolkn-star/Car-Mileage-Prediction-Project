#  Car Mileage Prediction using Regression, Linear Algebra & Calculus

This project demonstrates how **correlation analysis, linear regression, linear algebra, and calculus-based gradient descent** can be applied to predict car mileage based on engine size, weight, and horsepower.

###  Key Features

* Created a simulated car dataset using **NumPy and Pandas**
* Performed **correlation analysis** to identify relationships between vehicle features
* Built a **Linear Regression model** using Scikit-learn
* Calculated regression coefficients using the **matrix equation**:
  `β = (XᵀX)⁻¹Xᵀy`
* Implemented **Gradient Descent from scratch** to optimize slope and intercept
* Visualized correlations and regression results using **Matplotlib and Seaborn**
* Compared regression results from Scikit-learn, Linear Algebra, and Gradient Descent

###  Technologies Used

**Python | NumPy | Pandas | Matplotlib | Seaborn | Scikit-learn**

### Learning Objectives

The project provides a practical understanding of how mathematical concepts such as **correlation, regression, matrices, optimization, derivatives, and gradient descent** are used in machine learning.

**Project Type:** Machine Learning / Data Science
**Focus:** Regression & Mathematical Foundations of Machine Learning
